# Recortes dos lamalumenses

Criados com a ferramenta integrada ImageGen, com fundo transparente, a partir das imagens em assets/imagens/mundos/lamalume.

Arquivos: lamalumense-quadrado.png, lamalumense-redonda.png, lamalumense-triangular.png.

Prompt usado individualmente para cada personagem: Background-extraction edit. Remove ONLY the entire scenery and background from this image. Keep exactly the central [quadrado/redonda/triangular] brown mud character, its full body, arms, hands, feet, expression, texture and any object it holds, unchanged. Remove all ground, sky, landscape and background creatures. Clean isolated character cutout on true transparent alpha, centered with tight even transparent margins. Preserve original 3D illustration and pose. Output a PNG asset for a memory card game.
