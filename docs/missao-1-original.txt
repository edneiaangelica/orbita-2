Questões
A) Questões:
Você deve montar uma estrutura para 4 tipos de questões: 
Arrastar (usada para ordenar números, contar dinheiro) 
Arrastar tipo 1 (at1): ordenar cartas com números.
Arrastar tipo 2 (at2): Arrastar dinheiro para pagar, receber ou dar troco
Clicar na resposta (para perguntas diretas tipo: quem tem mais dinheiro?)
Digitar resposta (usada em operações)
Quiz ( com 4 alternativas de resposta)
Quiz tipo 1 (qt1): Enunciado = texto + imagem, alternativas = texto
Quiz tipo 2 (qt2): Enunciado = texto, alternativas = imagens
Quiz tipo 3 (qt3): Enunciado = texto, alternativas = texto
Quiz tipo 4 (qt4): Enunciado = texto + imagem, alternativas = imagem
